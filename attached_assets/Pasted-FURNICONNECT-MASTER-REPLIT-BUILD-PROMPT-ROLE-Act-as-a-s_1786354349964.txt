FURNICONNECT — MASTER REPLIT BUILD PROMPT

ROLE

Act as a senior full-stack SaaS architect, UI/UX designer, AI product engineer, marketplace developer and startup CTO.

Build a production-quality, responsive web application called FurniConnect.

FurniConnect is a Nigerian furniture and interior-design marketplace combined with a SaaS operating system for furniture makers, interior designers, showrooms, contractors and property developers.

The application must feel like a premium technology startup — not a generic directory or template.

The experience should combine the best characteristics of:

- Houzz
- Pinterest
- modern AI design applications
- Shopify
- CRM SaaS platforms
- premium real-estate marketplaces
- modern Nigerian fintech interfaces

The application must be mobile-first, extremely polished, fast, intuitive and visually impressive.

---

1. PRODUCT VISION

FurniConnect helps customers:

1. Discover furniture makers and interior designers.
2. Find professionals near their location.
3. Upload an empty room photo.
4. Enter room dimensions.
5. Select their preferred interior style.
6. Enter their budget.
7. Use AI to generate a complete furnished-room concept.
8. See recommended furniture and decor.
9. Find professionals who can execute the design.
10. Request quotations.
11. Compare providers.
12. Hire a provider.
13. Sign digital agreements.
14. Pay deposits/milestones.
15. Track the project.
16. Review the provider after completion.

For businesses, FurniConnect provides:

- Business profile
- Portfolio
- Leads
- CRM
- Quote builder
- Invoices
- Digital contracts
- Project management
- Customer management
- Payment tracking
- Analytics
- Team management
- AI tools
- Subscription management

The long-term positioning is:

«The operating system for Nigeria's furniture and interior-design industry.»

3. TECHNOLOGY

Use a modern Replit-friendly full-stack architecture.

Preferred:

- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Node.js
- Express or an appropriate modern backend
- PostgreSQL
- Prisma ORM
- React Query/TanStack Query where appropriate
- Zod validation
- Secure authentication
- Cloud/object storage abstraction for images

Structure the application cleanly so it can later scale into a multi-tenant SaaS.

Use environment variables for:

- DATABASE_URL
- AI API keys
- Payment provider keys
- Email provider
- Storage provider
- Maps/location services

Do not hardcode secrets.
